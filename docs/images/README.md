# Dashboard screenshots

The screenshots in this folder were captured from the verified USAspending FY2024–FY2025 snapshot and are included in the project README.

- `overview.png` — overview KPIs, principal findings, and dashboard navigation.
- `pareto.png` — vendor concentration by cumulative contribution.
- `abc.png` — distribution of ABC vendor classes.
- `fiscal-year-comparison.png` — annual comparison for NSF and NRC.

The historical empty-state screenshots (`overview-empty-desktop.png` and `overview-empty-mobile.png` in the parent folder) demonstrate the dashboard's behavior before data is loaded.

For updated screenshots, run `python -m streamlit run app.py` using the bundled official snapshot. Do not substitute fixture data in public project screenshots.
